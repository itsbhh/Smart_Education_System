# Smart_Education_System

Student Failure-Risk Prediction Using Data Mining
Platform: Google Colab
Algorithm: Decision Tree Classification
Dataset: 400 synthetic students, with an optional 401st new-student record

This notebook will:

Create and show the 400-student dataset.
Train a Decision Tree model and evaluate it.
Calculate a predicted result, failure probability and LOW/MEDIUM/HIGH risk level for every student.
Show a risk summary and the complete 400-row dataset in the output.
Let you enter a new student (for example, Student 401).
Show the complete updated 401-row dataset in the output.
Ask whether you want to download the 401-row dataset.
The 400 records are synthetic examples for a college project. Predictions and probability scores are demonstrations, not verified real-world failure probabilities. Use them only to guide supportive teacher review.
