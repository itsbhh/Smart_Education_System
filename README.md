# Smart_Education_System

## Student Failure-Risk Prediction Using Data Mining

**Platform:** Google Colab  
**Programming Language:** Python  
**Algorithm:** Decision Tree Classification  
**Dataset:** 400 Synthetic Students  
**Additional Record:** Optional 401st New Student

## Project Description

The Smart Education System is a machine-learning-based project designed to predict students' academic failure risk using Data Mining techniques.

It uses a Decision Tree Classification algorithm to analyze student data, predict academic outcomes, calculate failure probability scores, and classify students into LOW, MEDIUM, and HIGH risk categories.

## Features

1. Generate and display a dataset of 400 synthetic students.
2. Train a Decision Tree Classification model.
3. Evaluate model performance using classification metrics.
4. Predict academic results for all 400 students.
5. Calculate failure probability for every student.
6. Categorize students into LOW, MEDIUM, and HIGH risk levels.
7. Display a risk summary.
8. Display the complete 400-row prediction dataset.
9. Allow entry of a new student (Student 401).
10. Predict the new student's academic result and failure risk.
11. Display the complete updated 401-row dataset.
12. Ask whether to download the updated dataset as a CSV file.

## Risk Categories

| Risk Level | Description |
|---|---|
| LOW | Lower predicted failure risk |
| MEDIUM | Moderate predicted failure risk |
| HIGH | Higher predicted failure risk |

1. Open Google Colab.
2. Upload or open the project notebook.
3. Run all notebook cells in sequence.
4. View the generated 400-student dataset.
5. Check model evaluation results and predictions.
6. Enter new student details when prompted.
7. View the updated 401-student dataset.
8. Choose whether to download the CSV file.

## Dataset Information

The project uses 400 synthetically generated student records. An optional 401st student record can be entered manually to demonstrate predictions for a new student.

## Disclaimer

The dataset contains synthetic examples created for educational and college-project purposes. Predictions and probability scores are demonstrations, not verified real-world failure probabilities. The system is intended to support teacher review and identify students who may benefit from additional academic assistance. It should not be used as the sole basis for academic decisions.

## Project Objective

To demonstrate how Data Mining and Machine Learning techniques can help educational institutions identify students who may be at risk of academic failure and provide timely academic support.
